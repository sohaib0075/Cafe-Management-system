# ☕ Cafe Management System

A console-based Cafe Management System developed in C++ using Object-Oriented Programming (OOP) concepts. The system helps manage cafe operations such as customer orders, menu management, billing, and data storage through file handling.

## 📌 Overview

This project was developed to demonstrate the practical implementation of OOP concepts in C++. It provides an interactive menu-driven interface that allows users to manage cafe activities efficiently.

## ✨ Features

### Customer Management
- Add new customers
- View customer information
- Manage customer records

### Menu Management
- Display available food and beverage items
- Add new menu items
- Update existing menu items
- Remove menu items

### Order Management
- Place customer orders
- Generate bills automatically
- View order details
- Calculate total cost

### File Management
- Store customer records
- Save menu data
- Maintain order history
- Persistent data using file handling

## 🛠 Technologies Used

## 🚀 How to Run

### Compile

```bash
g++ main.cpp filemanager.cpp user.cpp -o cafe_management
```

### Execute

Linux / Mac:

```bash
./cafe_management
```

Windows:

```bash
cafe_management.exe
```

## 🔄 System Workflow

1. User launches the application.
2. Cafe menu is displayed.
3. Customer places an order.
4. System calculates bill automatically.
5. Order information is stored.
6. Customer and sales records can be viewed later.
